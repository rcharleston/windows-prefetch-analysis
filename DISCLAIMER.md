# Scope and credits

This repository documents a simulated training case. Initech and the named workstation user belong to the exercise scenario. No production incident, client data, malware, or original evidence bundle is included.

The exercise was created by **Eric Capuano** and encountered through the **Simply Cyber** community. [Original exercise reference](https://substack.com/@ecapuano/p-144084434).

**PECmd** and **Timeline Explorer** are Eric Zimmerman's tools; obtain them from [their official distribution](https://ericzimmerman.github.io/). They are not redistributed here.

Roman Charleston performed and documented the analysis in [the published walkthrough](https://medium.com/@romancharleston/prefetch-analysis-home-lab-4c9e376c9e01). The repository condenses that work into a reviewable case study. Some conclusions in the original narrative are hypotheses; the refreshed notes state those limits explicitly.
